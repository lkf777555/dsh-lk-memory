功能

把项目知识
变成会话上下文。

01

自动注入

会话开始时，项目记忆索引自动进入 system prompt；标记为强制规则的记忆整段置顶。

MEMORY.md → systemPrompt
02

可视化管理

在 DSH 记忆面板里搜索、编辑、新建、删除记忆，索引不一致时一键修复。

⌘
03

默认安全

只允许读写记忆目录内的 Markdown 文件，失效索引行自动过滤，写入前需要确认。

◈
04

只用 DSH

所有数据都在 ~/.dsh/memory 下，不读写 DSH 之外的任何目录。

~/.dsh/memory/projects/<slug>/memory/
工作方式

三步：
写入、定位、注入。

01

写入

把约定和决策保存成 Markdown 记忆，必须始终生效的可以标记 enforcement: required。

02

定位

DSH 根据会话工作目录找到对应项目的记忆目录。

03

注入

索引和强制规则成为 system prompt 的一部分，下一轮会话即可使用。

安装

两步接入。

CLONE
git clone https://github.com/lkf777555/dsh-lk-memory.git

把仓库克隆到本地任意目录。

ADD TO DSH
dsh plugin --profile desktop add link:<克隆路径>\dsh-lk-memory

用命令行接入 DSH，或在插件页用 Add plugin 选择该目录。更新时拉取最新代码后重启 DSH 即可。
