# dsh-lk-memory website

This directory contains the static GitHub Pages site for dsh-lk-memory. It has no build step and is intentionally excluded from the npm package.

- `index.html`: animated bilingual landing page
- `changelog.html`: bilingual release history page
- `styles.css`: dark visual system and responsive layout
- `script.js`: language switch, scroll reveal, pointer glow, tilt card, menu, and memory cycling
